C411 en direct

Celle indiquée par C411 pour Radarr / Sonarr (https://c411.org ou https://c411.org/api).
La même clé que dans Radarr / Sonarr (profil C411).

Prowlarr (indexeur C411)

Adresse de Prowlarr telle que vue depuis le serveur Jellyfin.
Prowlarr > Settings > General > API Key.
Uniquement pour un Prowlarr du réseau local avec un certificat auto-signé. À ne pas utiliser pour un Prowlarr accessible par Internet : la clé API pourrait être interceptée. La raison exacte d'un refus de certificat est écrite dans les journaux Jellyfin.

Téléchargement et rangement automatiques

Remplace l'application « RealDebrid » + Radarr / Sonarr pour les demandes faites ici. Désactivez la récupération automatique de l'ancienne application, sinon les fichiers seront téléchargés deux fois.
Chemin vu par le serveur Jellyfin. Rangement : Titre (2010) [tmdbid-27205]/Titre (2010) Bluray-1080p.mkv
Rangement : Titre (2008) [tmdbid-1396]/Season 01/Titre - S01E01 - Nom de l'épisode WEBDL-1080p.mkv. Une série déjà présente garde son dossier actuel.
Rangement : Titre (2015)/Titre (2015).epub ; un pack (intégrale, numéros de presse) garde le nom de chaque fichier. Facultatif si vous ne demandez pas de livres.
Nombre de fichiers téléchargés en même temps depuis Torbox, toutes demandes confondues (1 à 10). Plusieurs épisodes d'un pack de saison comptent chacun pour un.
Libère un emplacement sur Torbox. Les fichiers rangés sur le NAS ne sont pas touchés.

Validation automatique

S'il ne dépasse pas la taille max de son type ci-dessous, quels que soient ses seeders (taille max à 0 : sans limite).
0 = jamais de validation automatique par la taille pour ce type, et pas de limite pour un torrent en cache Torbox.
En dessous, la demande part en validation admin même si elle est sous le seuil de taille.

Notifications

Les notifications sont toujours visibles dans la page des demandes ; le webhook les envoie en plus sur Discord.
Validation, refus (avec son motif) et disponibilité, précédés du nom du demandeur. Décoché : seules les notifications des administrateurs partent sur Discord.

Suivi et ménage

Prévient les administrateurs d'une demande toujours en cours (torrent sans source, média non reconnu par Jellyfin…) après ce nombre de jours. 0 = désactivé.
Les demandes disponibles, refusées ou annulées sont ensuite supprimées. Les demandes en cours ou en échec sont toujours gardées. 0 = jamais.
0 = jamais supprimées. Le ménage se fait chaque nuit (Tâches planifiées → « Ménage des demandes »).
